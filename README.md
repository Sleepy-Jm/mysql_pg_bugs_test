# MySQL 与 PostgreSQL 报告重放实验

两个数据库分别维护来源、SQL/oracle、执行记录与版本边界，不合并统计。

| 工作线 | 入口 | 当前统计口径 |
|---|---|---|
| MySQL | [mysql/](mysql/README.md) | 原仓库全部内容与历史证据整体移入；原统计不变 |
| PostgreSQL | [pg/](pg/README.md) | 136 份报告；保存 67 份可执行历史快照及补齐后的 68 份最新结果 |

PG 最新目标版本结果：63 份复现报告现象、2 份有效未复现、3 份已执行但无法判断，另有 68 份尚无可执行场景。共 70 个场景、210 个场景 × 版本执行项。报告现象不等于独立 bug；相邻版本现象消失不等于已确认修复提交。

原 MySQL 相对路径保持在 `mysql/` 内，运行其脚本前先 `cd mysql`；PG 工具前先 `cd pg`。旧 MySQL 提交历史保留，历史链接可按原提交访问。
