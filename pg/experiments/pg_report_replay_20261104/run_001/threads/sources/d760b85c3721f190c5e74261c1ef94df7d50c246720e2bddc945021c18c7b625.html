Bug reference: 18718
Logged by: Guido K
Email address: guidoakiu(at)gmail(dot)com
PostgreSQL version: 17.1
Operating system: Windows
Description:

Dear PostgreSQL Community Team,

I hope this message finds you well.

I would like to bring to your attention a small issue on the PostgreSQL
documentation page. While browsing, I noticed that the Twitter logo
displayed still features the old bird icon instead of the updated "X" logo
following Twitter's recent rebranding.

As Twitter has transitioned to its new identity as "X," updating the logo on
your website would help maintain visual consistency and reflect the current
branding accurately.

Thank you for your continued efforts in maintaining such a valuable resource
for the PostgreSQL community. Please feel free to reach out if you need
further clarification regarding this matter.

Best regards,
Guido

under Community or Support and reclaim some vertical space (the Git link can
also be removed, few if any will likely be helped by that).
