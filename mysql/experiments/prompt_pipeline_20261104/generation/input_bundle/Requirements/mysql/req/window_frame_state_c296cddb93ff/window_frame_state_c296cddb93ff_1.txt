Correctness oracle
For each output row enumerate precisely the rows in its partition and frame, discard NULL values for AVG, and divide their sum by their count. An empty or all-NULL frame yields NULL. Compute FIRST_VALUE/LAST_VALUE from the ordered frame, including ordinary MySQL NULL behavior. Use manual arithmetic and, where practical, a non-window correlated aggregate over the base data as an independent oracle. SUM(...) OVER / COUNT(...) OVER is useful as a diagnostic, but is not the sole oracle because the window functions may share faulty frame state. Comparison with the parent revision supplements rather than defines correct semantics.
