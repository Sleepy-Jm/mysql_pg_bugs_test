## 视图计数 T2

脚本将第一张表的 5 行按值去重，得到 `1`、`2` 和一个 `NULL`。再合并第二张表的 2 行，正确答案为 **5**。对照分别计算后相加。[原始 T2](../../stage12_generation_20261119/run_20261119_124816/cases/SQLite/d1ba200234f40b84/sql/T2.sql)

| 比较边界 | 旧侧目标 / 对照 | 新侧目标 / 对照 |
|---|---|---|
| 原始引入，默认构建 | 5 / 5 | 5 / 5 |
| 原始引入，父子均设置 `SQLITE_COUNTOFVIEW_OPTIMIZATION` | 5 / 5 | 7 / 5 |
| 后续默认启用提交，默认构建 | 3 / 5 | 7 / 5 |
| 官方修复，默认构建 | 7 / 5 | 5 / 5 |

每个单元格的结果在三轮中均相同。后续默认启用提交的父版本已经返回错误计数 3，单靠该版本对不能判定“首次算错”。本例的归因依据是原始引入的同配置对照、官方修复边界以及可手算的独立预期。
