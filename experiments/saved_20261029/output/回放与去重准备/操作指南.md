# 版本回放与根因去重准备

本目录由已冻结候选生成；数据库执行数为0，所有结果为null。准备类型只是调度信息，不表示脚本已就绪、版本已受影响或相邻版本正常。

## 文件与准备顺序

1. `candidate_replay_tasks.json`保留每个报告—目标版本的原判读、锚点、测试说明及环境条件。原候选没有明确test_spec时进入manual_preparation；other/未知kind进入unknown，须先补完整用例。kind来自保存的判读，不能替代实际脚本审查。
2. 按报告整理DDL、数据、会话顺序、预期行为及清理步骤；同一报告若含多个现象，创建不同variant_id，分别绑定源码/原文锚点。保留原例与最小化例，分别记录哈希，不覆盖原证据。暂不生成数百份空SQL或把网页说明自动当成脚本。
3. 在`environment_template.json`填写目标/相邻版本的实际二进制身份、构建类型、镜像digest或源码提交、平台、CPU、配置、SQL模式、字符集/排序规则、时区、优化器开关、存储引擎和资源限制。复制/多会话/升级/性能/Debug类须专用环境；常规x86_64结果不能代替其他平台。
4. 把准备完成的脚本哈希、原文依据、oracle与环境清单绑定至variant_id。先跑已知正常/异常对照验证检测器。初始化失败、连接失败、语法/特性不支持、资源中断分别标blocked或inconclusive，不能记为缺陷或正常结果。实际执行前完成隔离环境、日志和超时配置。
5. `planned_runs.json`为每个候选安排目标与相邻版本各3次，使用独立新库/容器重置，保存stdout、stderr、服务端日志、实际版本、返回码、耗时、配置和测试文件SHA256。重叠的版本任务默认独立执行，不能无依据复用其他候选结果。多节点用例中的一行代表一次完整拓扑试验，不是单实例命令。
6. 每次执行按`result_template.json`单独追加记录，禁止改写本次准备包中的历史结果。wrong_result、error_difference、plan_diff、crash、performance分开判定。退出码非零不能独自证明崩溃；性能/计划问题须自己的阈值、重复测量与对照。3次只是初始稳定性检查，性能实验需要另外冻结样本量和噪声控制。
7. 同一oracle和variant下相邻版本3次正常、目标3次异常，才报告该环境下的发布版本行为边界；这不自动证明精确introducing commit。两侧都异常记pre_existing_observation；差异不稳定记inconclusive。复现数和版本引入数按独立证据分别统计。

## 根因去重

`root_cause_review.json`按报告汇集跨版本候选，root_cause_id初始均null。它只是报告索引，不是已去重的bug集合。一个报告可含多个根因，需按variant拆分；不同报告也可能同根因。

`relation_hints.json`仅保留已有正文链接指向其他MySQL报告的关系线索和原文锚点；普通引用不等于Duplicate，不能自动归并。duplicate_status也是原队列标记，不能当作已验证关系。人工/AI复核需读取关系上下文，记录保留或撤销、版本/现象范围及冲突。

先按现象候选配对，再比较最小复现、失败算子/函数、栈、触发条件、相邻版本边界及引入/修复提交。相同错误信息、栈顶、版本或标题不足以合并。确认同根因须有原始关系证据或技术归因，记录排除其他解释的理由；证据不足保持unknown，不把每份报告强行算一个bug。使用`dedup_decision_template.json`保存决定和证据，保留拆分/撤销历史。

## 历史启动用例

若生成时提供--historical-root，`historical_starters/`保存原有9份SQL及可用原始结果JSON/崩溃日志，逐文件记录SHA256。它们是历史复现材料，未按本轮协议重跑；如与当前候选不重叠，只作独立校准用例。复制SQL不等于完成脚本兼容、清理或oracle审核；本轮执行统计始终从0开始。初始化失败的attempt1单独标无效历史尝试，不混入有效执行。

## 复算

    python -B scripts/prepare_replay_dedup.py --plan 验证任务.json --output 回放与去重准备

首次生成可加`--historical-root 原mysql-bug-audit目录`复制历史启动材料；交付后的再次生成可用`--historical-root 回放与去重准备/historical_starters`。来源参数缺失时只生成新轮计划，不能伪称已携带历史文件。输出目录须为空，避免覆盖已有回放结果。脚本不连接数据库、容器或网络。
