前提与顺序
一个新连接，已选择可丢弃 schema，临时表名空闲；目标构建须支持所列窗口语法、DECIMAL 转换和 windowing_use_high_precision。该名称来自 R8，不猜加其他开关。脚本保存初始精度设置，执行非 NULL 基线、边界/分区对照、NULL 变体、REAL 的 0/1 设置对照，最后清理自建临时表并恢复设置；错误时停止并恢复设置/关闭连接。本阶段没有数据库验证版本/语法，也不保证优化分支命中。

独立数学 oracle
各 p 按唯一 id 排序。主分区输入为 [60,180,120,300,240,420,360,540,480]；短分区 [120,300] 和单行分区 [240] 分开计算。WF_BASE 只取主分区；其余按 SQL 中的阶段数据。
主帧在 i 行为 [max(1,i-2),min(n,i+3)]。上界 CURRENT ROW 和 UNBOUNDED FOLLOWING 分别替换为 i 和 n；累计对照下界为 1。WF_EMPTY 的下界 i+2、上界 min(n,i+3)，下界超过上界为空。每个帧忽略 NULL，独立计算和 s、计数 k，k=0 返回 NULL，否则平均 s/k。
NULL 阶段主分区 id 2,5,8 同时把 v 和 r 改为 NULL；新增 p=4 的三行全 NULL。例如离开帧的 id2 在 i5 下界变为3时排除；尾部 id8 的 NULL 在保留帧内。空帧和全 NULL 帧均不把 NULL 当 0。
DECIMAL 输入为精确整数，使用显式 CAST(... AS DECIMAL(18,6)) 固定比较小数位，按正数十进制最近舍入（中点向上）计算；无溢出风险。expected 中小数字符串按数值比较，客户端尾零不同可归一化。基线移动帧最多6行，输入都是60的倍数，分母1..6均整除60，所以非 NULL 平均为整数，避免未知 AVG 中间返回尺度影响主要观察。累计对照出现非整数，用6位目标尺度。
REAL 两个设置使用相同 NULL 阶段数据；帧最多6行，所有输入、和及数学平均均为可二进制精确表示的小整数。采用绝对1e-10、相对1e-12两者较大容差，只容纳浮点累计/传输尾差；NULL 精确比较。高/低设置查询不是彼此的唯一 oracle，逐行帧枚举才是。
每个输入行有唯一 (p,id)，每个 case 每个键恰好一行；无重复行丢弃，无字符集比较。

覆盖观察计划（只转述冻结需求）
记录策略互斥状态、row_optimizable、aggregates_primed、current_row、lower_limit、upper_limit、upper、last_rowno_in_cache、unbounded_following、remove_previous_first_row、new_last_row 和 rows_in_frame。
主分区尾部 i7..9 的数学帧为5..9、6..9、7..9，起点继续移动而上端不新增成员；这只是 SQL 语义，不能据此认定内部 remove/new_last 标志或优化路径。
区分移除调用和添加调用，记录恢复行身份、inverse/last、rowno_in_frame 的每次设置。AVG 消费点记录实际类型、needs_buffering、m_count、m_frame_null_count、除数，与表格的成员/非 NULL 数独立对照。R8 精度开关仅是局部资格条件，需确认 AVG 的继承/调用关系；DECIMAL 路径同样要核验 hybrid_type。
短分区、单行和全 NULL 分区用于观察重置；它们不触发移除路径也不能归为复现失败。EXPLAIN 仅为计划线索。FIRST/LAST/NTH 扩展依照 C5 的先决条件阻塞，没有宣称覆盖该类函数。
